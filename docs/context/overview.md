# プロジェクト概要

## サービスの目的
タイピング初心者向けの、日本語ローマ字入力の練習アプリ。
ミスの傾向を可視化し、利用者が自分の苦手なキーを把握できるようにする。

## 主要なドメイン概念
- **お題**：練習で入力する日本語の単語。表示用の表記と、かなの読みを持つ。
- **ローマ字の入力パターン**：1 つのかなに複数のローマ字表記がある場合（例：「し」= `si` / `shi`）、どの表記でも正解とする。
- **セッション**：1 回の練習。お題 10 問で区切る。
- **キーごとの集計**：キーごとに「打つべきだった回数（出現回数）」と「ミスした回数」を数える。ミスは押し間違えたキーに数える。
- **苦手キー**：ミス率（ミスした回数 ÷ 出現回数）が高いキー。出現回数が少ないキーは判定しない（初期値：出現 10 回以上のキーのうち、ミス率の上位 5 キー。値は使いながら調整する）。
- **記録**：打鍵を 1 回ずつ（打つべきキー・押したキー・直前のキー）ローカルに保存し、セッションをまたいで集計する。

## アーキテクチャ／ディレクトリ構成
ローカルで動かす Web アプリ（デプロイしない）。ブラウザで動く画面と、記録を保存するローカルのサーバーに分ける。
- `src/client/` — 画面（練習画面・結果・苦手キーの表示）
- `src/server/` — 記録の保存と集計の API、SQLite へのアクセス
- `src/shared/` — 画面とサーバーで共有するもの（ローマ字の判定ロジック、型、お題の単語リスト）

## 技術スタック
- 言語：TypeScript
- 画面：React + Vite
- サーバー：Node.js + Hono
- 記録：SQLite（better-sqlite3）。ローカルのファイル 1 つに保存する
- テスト：Vitest

## 開発・テストの実行方法
- 前提：Node.js 22.12 以上（`.nvmrc`）、pnpm 9.14.2（`package.json` の `packageManager`）
- `pnpm install` — 依存の導入（better-sqlite3 のネイティブビルドを含む）
- `pnpm dev` — 画面（Vite、http://localhost:5173）とサーバー（Hono、http://127.0.0.1:3000。127.0.0.1 だけで待ち受ける）を同時に起動する。画面の `/api` へのリクエストは Vite の proxy でサーバーへ転送する
- `pnpm test` — テスト（`vitest run`。`vitest` だけだと監視モードで終わらないため）
- `pnpm lint` — lint と format の検査（Biome）。`pnpm format` で自動修正する
- `pnpm typecheck` — 型チェック（`tsc --noEmit`）
- 記録の SQLite のファイルは `data/typing.db`（git 管理外）
- CI（`.github/workflows/flow-ci.yml`）が、PR と main への push で `pnpm test`・`pnpm lint`・`pnpm typecheck` を実行する（`docs/flow.config.yml` の `commands` と同じ順）
